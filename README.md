# Student Planner App

A lightweight planner app aligned to the Group 2 SRS with:

- To-Do module (add, edit, complete, delete, due date, priority)
- Calendar module (Day/Week/Month views with add, edit, delete events)
- Timer module (set minutes, start, pause, reset, completion alert)
- Automatic local save/load persistence for tasks and events

## Run

1. Double-click `dist/Student Planner.app` to launch the planner.
2. Or open `index.html` directly in your browser.
3. Use the tabs for To-Do, Calendar, and Timer features.

No build or dependency installation is required.
