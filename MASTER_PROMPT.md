# Master Prompt

Build a student planner app for a software engineering project.

Requirements:
- Include a to-do list for the current day.
- Include a week view.
- Include a month view.
- Allow users to add events to the calendar.

After building the app, provide a complete Software Requirements Specification (SRS) for the system.

SRS should include at minimum:
- Introduction and scope
- User roles and assumptions
- Functional requirements
- Non-functional requirements
- UI/interface requirements
- Acceptance criteria
